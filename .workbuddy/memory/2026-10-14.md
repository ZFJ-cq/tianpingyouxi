# 2026-10-14 称量台 MVP 完成

## 今日成果

从零建成「称量台·天平找伪币逻辑推理挑战」完整 MVP（项目目录 `/Users/macbook/前端项目/硬币天平/`）：

- **技术栈**：Next.js 14.2.32 App Router + TS + Tailwind 3.4 + zustand 4 + framer-motion 11，`output:'export'` 纯静态，无后端，localStorage 持久化。UI 为手写 shadcn 风格令牌组件（未用 shadcn CLI，避免网络交互）。
- **核心模型**：每枚硬币 roles ∈ {[], [L], [H], [L,H]}；剩余可能数 = Σ|roles|。称量按 平衡/左倾/右倾 更新（盘上洗清或按方向收窄、盘外平衡时不变/倾斜时洗清）。
- **solver（src/game/solver.ts）**：极小化极大 + 分组等价（状态压缩为 (L,H,B,G) 四元组，G=已确定正常币可作配重）+ 五重剪枝（L/H 规范化、盘面镜像去重、轻重镜像去重仅当 L===H、信息论下界提前退出、不可行剪枝）+ 记忆化 + 20 万节点预算。实测最坏 19ms。
- **关键建模发现**：状态必须追踪正常币数量 G——经典 12 币题第二步「2 疑币 vs 1 疑币 + 1 正常币」靠配重把 8 候选劈成 3/3/2；没有 G 则 12 球 3 次无解。称量合法性约束是 |Σ左−Σ右| ≤ G（而非两盘疑币数相等）。
- **关卡最优次数（solver 验证）**：8/9/12 未知=3，13 未知=4（26≤3³ 但首称三分无法同时 ≤9，信息论下界不可达），27 未知=4；已知档 8/9=2、12=3、27=3。
- **UI**：SVG 天平（横梁/双托盘/V 形吊线/表盘指针/底座），framer-motion 弹簧倾斜，托盘由倾角解析推导位置（沿弧平移且保持水平）；硬币 SVG 渲染带角色渐变；待选区点击多选 + 按钮入盘 + pointer 事件拖拽（ghost 跟手、分区高亮、tap/drop 区分）；右侧栏（剩余可能/预算/可能集小格/推理路径可点击跳回放）；提示横幅一键应用；结算模态框；复盘回放（自动/单步）。
- **测试**：Node 套件 1069 项断言全过（tests/，esbuild 打包后 `npm test`）；浏览器回归探针 `/selftest/` 147 项全过（含 Web Worker 回环 + 驱动真实 store 的完整对局 E2E：提示驱动通关、猜错判负、回放、正常币配平）。无头 Chrome 冒烟 + 截图验证渲染（左倾状态、角色配色、可能集网格均正确）。

## 踩坑记录

1. **enumerateMoves 别名 bug**：回溯时把同一个 acc 数组引用 push 进结果集，导致全部条目是空数组（solver 全返回 INF）。必须 `acc.slice()` 拷贝。
2. **minWeighings 浮点**：`Math.ceil(Math.log(27)/Math.log(3))` = 4（3.0000000000000004）。改用整数循环 `while (p < n) { p *= 3; k++ }`。
3. **tsc 增量缓存**：改 tsconfig（加 target ES2020）后旧 `tsconfig.tsbuildinfo` 不失效，报陈旧错误。删掉即可。
4. **Next 静态导出 + Web Worker**：`new Worker(new URL('./x.worker.ts', import.meta.url), {type:'module'})` 会被 webpack 拆成独立数字 chunk（如 541-*.js），grep 文件名搜不到 "worker"；basePath 经 `n.p` 自动继承，无需手改。
5. **无头 Chrome 虚拟时间与 Worker IPC**：selftest 含 worker 回环 + sleep 的 E2E，`--virtual-time-budget=15000` 会假死（停在 running…），需 ≥120000。worker 消息不推进虚拟时间。
6. **后台起 http.server 会随 bash 会话被杀**：要用 run_in_background=true 起服务，否则后续 Chrome 请求连接失败、dump 为空文件。
7. **zustand persist 水合**：静态导出 SSR 烤入默认状态，客户端 localStorage 水合会不一致——用 mounted 门控（先渲染 loading splash）。
8. **沙箱 safe-delete**：`next build` 清 .next 会触发批量删除确认，需 `env -u CODEBUDDY_SAFE_DELETE_BULK_STATE_DIR -u CODEBUDDY_TOOL_CALL_ID`。
